# منصة فرق التقويم المدرسي

منصة لرؤساء فرق التقويم المدرسي وضباط الجودة: بيانات الفرق والزيارات، وتقويم الأعضاء وفق المعايير الثمانية، ولوحة مؤشرات وتقارير PDF وExcel.

مبنية بـ Next.js 16 وSupabase (قاعدة بيانات Postgres + تسجيل الدخول + صلاحيات على مستوى الصفوف RLS).

## التشغيل لأول مرة

### 1. إنشاء مشروع Supabase
1. أنشئ مشروعًا من [supabase.com](https://supabase.com/dashboard).
2. من **SQL Editor** شغّل ملفات `supabase/migrations` بالترتيب، كل ملف كاملًا ثم **Run**:
   `0001_init.sql` ثم `0002_ensure_profile.sql` ثم `0003_grants.sql` ثم `0004_directives_status_stats.sql` ثم `0005_issues.sql` ثم `0006_support_role.sql`.
   ضع شعار الهيئة في `public/logo.png` (يظهر في الصفحات وصفحة الدخول).
3. أضف بريدك كأول ضابط جودة (من SQL Editor):
   ```sql
   insert into public.allowed_emails (email, role, full_name)
   values ('your.email@example.com', 'officer', 'اسمك');
   ```
4. من **Authentication → URL Configuration** ضع في **Site URL** رابط الموقع (مثلًا `http://localhost:3000` أثناء التطوير) وأضف `http://localhost:3000/auth/callback` إلى **Redirect URLs**.

### 2. ربط التطبيق
انسخ القيم من **Project Settings → API Keys** إلى الملف `.env.local`:
```
NEXT_PUBLIC_SUPABASE_URL=https://xxxx.supabase.co
NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY=sb_publishable_...
```

### 3. التشغيل
```bash
npm install
npm run dev
```
افتح http://localhost:3000، اختر **إنشاء حساب** ببريدك، ثم أكّد البريد من الرسالة الواردة.

## كيف تعمل الصلاحيات
| | رئيس الفريق | ضابط الجودة |
|---|---|---|
| إنشاء حساب | فقط إذا أضاف ضابط الجودة بريده | فقط إذا أضيف بريده كضابط جودة |
| بيانات الفريق والأعضاء والزيارات | فريقه فقط | جميع الفرق |
| تقويم الأعضاء (8 معايير) | أعضاء فريقه فقط (لا يقوّم نفسه) | جميع الأعضاء بمن فيهم الرؤساء |
| رؤية التقويمات | تقويماته فقط | جميع التقويمات |
| زيارة ضابط الجودة للفريق | — | يسجلها لأي فريق |
| لوحة المؤشرات، سجل الفرق، التقارير، المستخدمون | — | ✓ |

- **سحب مستخدم من النظام:** من صفحة *المستخدمون* اضغط "سحب من النظام". يُحذف حسابه فورًا ولا يستطيع الدخول، وتبقى بيانات فريقه محفوظة. يمكن ربط الفريق برئيس جديد من صفحة الفريق.
- **الدعم الفني:** يضيفه ضابط الجودة من صفحة *المستخدمون* بدور «دعم فني». يرى شاشة البلاغات فقط: يطلع على جميع البلاغات ويغيّر حالتها ويكتب ملاحظة المعالجة، ولا يرى الفرق أو الزيارات أو التقويمات أو المستخدمين أو التوجيهات، ولا يحذف البلاغات.
- الصلاحيات مطبقة داخل قاعدة البيانات نفسها (RLS)، لا في الواجهة فقط.

## هيكل المشروع
- `supabase/migrations/0001_init.sql`: الجداول والصلاحيات والمعايير الثمانية.
- `src/app/(app)/team`, `visits`: صفحات رئيس الفريق.
- `src/app/(app)/dashboard`, `teams`, `reviews`, `reports`, `users`: صفحات ضابط الجودة.
- `src/app/api/export`: تصدير Excel.
- `src/lib/constants.ts`: المعايير ومستويات التقويم وحالات الزيارة.
